# Contributing to LinkedIn Job Scraper Agent

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## 🚀 Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/linkedin-job-scraper.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes thoroughly
6. Commit with clear messages: `git commit -m "Add feature: description"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Open a Pull Request

## 📋 Code Style

- Follow PEP 8 style guidelines
- Use meaningful variable and function names
- Add docstrings to functions and classes
- Keep functions small and focused
- Comment complex logic

## 🧪 Testing

- Test your changes manually before submitting
- Ensure existing functionality still works
- Add test cases for new features if possible

## 💡 Feature Requests

Have an idea? Open an issue with:
- Clear description of the feature
- Use cases and benefits
- Any implementation ideas

## 🐛 Bug Reports

Found a bug? Open an issue with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
- Your environment (OS, Python version, etc.)

## 📝 Pull Request Guidelines

- Keep PRs focused on a single feature/fix
- Update README.md if needed
- Ensure code follows project style
- Test thoroughly before submitting
- Respond to review feedback

## ⚠️ Important Notes

- Never commit credentials or `.env` files
- Respect LinkedIn's terms of service
- Be responsible with web scraping
- Consider rate limits and ethical usage

## 🙏 Thank You!

Your contributions help make this project better for everyone!
